## 📌 Project Overview
This project focuses on classifying primary gamma rays against cosmic ray background (hadrons) using data collected by the atmospheric Cherenkov **MAGIC Telescope**. Using Monte Carlo generated simulations of high-energy gamma-ray events, the goal is to perform data preprocessing, feature normalization, class balancing, and model comparison to accurately distinguish gamma showers (`g=1`) from hadronic background noise (`h=0`).
